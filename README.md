### Hi, I'm Thịnh 👋

AI Automation Engineer in Ho Chi Minh City.
I design and run AI agents and automation for a multi-market fashion retailer (Vietnam, Thailand, Cambodia, Myanmar, Canada).

**What I build**

- **Operations agents on chat apps** (Zalo, LINE, WhatsApp, Telegram): executive briefs, store alerts, shift-schedule and work-plan review, task follow-up.
- **Merchandising tools**: new-stock allocation, size reorder, inter-store transfer proposals, with a human approval step.
- **Data plumbing**: POS, e-commerce and ads data synced into one SQL warehouse, so every agent reads the same numbers.
- **Workflow automation on n8n**: SEO, content, social listening and recruitment pipelines in daily production.

**How I work**

- Agent = prompt + read-only tools: code fetches and renders, the model judges, nothing writes to a business system without a guard.
- Every agent is tested with a scripted model on real data before the first paid API call.
- Measure outcomes, not outputs: an agent is done when its proposals are acted on and the result is measured.
